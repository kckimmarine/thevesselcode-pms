## 1. 목적

PERFECT MARINE SOLUTION의 품질경영시스템 문서와 기록을 통제하여 최신·유효 상태를 유지한다.

## 2. 적용범위

`pms-iso-audit/` 하위 모든 관리 문서 및 ISO 심사 증빙 기록.

## 3. 책임

| 역할 | 책임 |
|------|------|
| 최고경영자 | 매뉴얼 승인 |
| 관리대표 | 절차 승인, 내부심사 |
| 문서 담당 | 등록·배포·보관 |

## 4. 절차

1. **작성** — 담당자가 `05-forms-templates/` 양식 또는 Markdown 초안 작성
2. **검토·승인** — 관리대표(절차) 또는 최고경영자(매뉴얼)
3. **등록** — `DOCUMENT-REGISTER.md`에 Doc ID, Rev, 승인일 기록
4. **배포** — git 저장소 또는 사내 공유 위치 (민감 기록은 `incoming/` 로컬만)
5. **개정** — Rev 증가, 개정 이력 표 갱신
6. **보존** — 기록 보존 기간은 법규·계약에 따름 (최소 인증 주기 + 1년 권장)

## 5. 관련 문서

- `DOCUMENT-REGISTER.md`
- `config.json`

## 6. 기록
