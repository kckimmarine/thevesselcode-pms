[TVC-PMS v1.0.1 App Update — 후배 전달용 (v1.0.0 → v1.0.1)]

■ 대상
  - 이미 v1.0.0 Setup으로 설치·사용 중인 PC (HQ / Engine / Deck / Master)
  - Seat license 재발급 불필요
  - 업무 데이터(Master / Work History / Requisition / Sync)는 AppData IndexedDB에 그대로 유지

■ 전달 파일 (1개만)
  dist/tvc_app_update_1.0.1_2026-08-17.zip  (약 329 MB)
  ※ 카톡보다 Drive / OneDrive 링크 권장

■ 후배 설치 방법 (각 PC · 해당 SKU 앱에서)
  1. TVC-PMS 실행 (HQ / Engine / Deck / Master 중 본인 PC SKU)
  2. Menu → Data Export & Import → Import → App Update
  3. 받은 ZIP 선택 → Install update
  4. 설치 마법사 완료 → 앱 재실행
  5. 로그인 화면 footer **v1.0.1** 확인
  6. 기존 Work History / Master / Requisition 데이터 그대로 있는지 확인

■ 데이터 유지 원리
  - App Update = 프로그램(Setup.exe)만 교체
  - IndexedDB·license·AppData 폴더는 설치 마법사가 건드리지 않음
  - Sync ZIP / Master Import 와 다름 — 업무 데이터는 변경되지 않음
