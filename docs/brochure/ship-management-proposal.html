02 · The Vessel Code — 디지털 관리

03

The Vessel Code (TVC-PMS)는 HK Shipping Inc 선박관리의 디지털 운영 기반입니다. BSM의 LiveFleet이 클라우드 실시간 대시보드를 제공하는 반면, TVC는 선박의 오프라인 환경에 최적화되어 항해 중·저속 위성망에서도 PMS·재고·결함 업무를 수행하고, 본사와 ZIP Export/Import로 안전하게 동기화합니다.

TVC 모듈

모듈기능선주 가치
PMSDeck/Engine 정비계획, Work Report, Overdue정비 이력·PSC 대비
SPARE부품 재고, 소모, 자동 차감이중 차감 방지, 비용 통제
Defect Report결함 등록 → 확인 → HQ 승인결함 이력 단일화
Work Permit작업허가 워크플로안전관리 문서화
Sync (ZIP)선박↔HQ 부서별 Export/Import오프라인 선박 환경 대응

업무 워크플로

작성자 (갑판/기관) → Save (Reported) ↓ 확인자 (기관장/선장) → Confirm (+ 스케줄·재고 규칙) ↓ HQ 승인자 → Approve (잠금) ↓ 선박 ↔ HQ → ZIP Export/Import

TVC vs 클라우드 플랫폼

클라우드 (LiveFleet 등)TVC (오프라인 우선)
연결상시 인터넷 필요선박 PC 로컬 동작
데이터서버 중심IndexedDB + ZIP 동기화
선박 환경위성·항만망 의존항해 중 업무 가능
비용구독·통신 비용로컬 설치, ZIP 전송
