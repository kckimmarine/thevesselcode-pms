# 쉬운 설정 (5분) — Supabase 화면만

**DATABASE_URL · Cursor Secrets · 터미널 없이** Supabase 웹에서만 끝낼 수 있습니다.

지금 보신 **Database → Settings** 는 연결 문자열이 **없는** 페이지입니다.  
아래 순서만 따라가면 됩니다.

---

## ① SQL 한 번 실행 (2분)

1. 왼쪽 메뉴 **SQL Editor** (터미널 아이콘) 클릭  
2. **New query**  
3. GitHub/로컬의 **`deploy/ALL-IN-ONE.sql`** 파일 **전체** 복사 → 붙여넣기  
4. 오른쪽 **Run** (또는 Ctrl+Enter)  
5. 하단에 **Success** 나오면 OK  

> 테이블·체크리스트·증빙 버킷이 한 번에 만들어집니다.

---

## ② 로그인 계정 만들기 (1분)

1. 왼쪽 **Authentication** → **Users**  
2. **Add user** → **Create new user**  
3. **이메일·비밀번호**를 **본인이 기억할 값**으로 입력 (원하는 대로)  
4. **Create user**  

이게 포털 로그인용입니다. Supabase에 미리 있는 값이 아닙니다.

---

## ③ 관리자 권한 연결 (1분)

1. 다시 **SQL Editor** → New query  
2. **`deploy/STEP3-ADMIN.sql`** 열기  
3. `'여기에-본인-이메일@example.com'` 을 **②에서 넣은 이메일**로 바꾸기  
4. **Run**

---

## ④ 포털 주소 넣기 (1분)

**Settings → API Keys** 에서:

- **Project URL** (General에도 있음): `https://vthtjthxbfepephctnax.supabase.co`  
- **Publishable key**: `sb_publishable_…`

(나머지 줄은 그대로 두어도 됩니다.)

## ⑤ 포털 열기

로컬에서 repo가 있으면:

```bash
npm start
```

브라우저 **http://localhost:3010** → ②에서 만든 **이메일·비밀번호**로 로그인.

---

## 안 해도 되는 것

| 항목 | 이유 |
|------|------|
| DATABASE_URL | SQL Editor로 대체 |
| Cursor Secrets | 필수 아님 |
| PMS_ISO_ADMIN_EMAIL | ②에서 화면으로 사용자 생성 |
| Database → Settings | 연결 문자열 없음 — 무시 OK |

## 막히면

- SQL 오류 → `ALL-IN-ONE.sql` 다시 Run (여러 번 해도 됨)  
- 로그인은 되는데 데이터 안 보임 → ③ ADMIN SQL 이메일 확인  
- 증빙 업로드 실패 → Storage에 `iso-evidence` 버킷 있는지 확인  

도움이 필요하면 **어느 단계(①~⑤)** 에서 막혔는지만 알려 주세요.
