# PMS ISO 포털 시작

> **권장:** `thevesselcode-pms`와 **분리**하려면  
> [`docs/CURSOR-별도-프로젝트.md`](../templates/perfect-marine-solution-iso/docs/CURSOR-별도-프로젝트.md)  
> → GitHub `perfect-marine-solution-iso` repo를 **새 Cursor 창**으로 열고, 채팅 **「Pms iso 심사 서류」** 사용.

아래는 **이 앱 repo 안**에서 빠르게 테스트할 때만 사용합니다.

## 1. 터미널

```bash
cd pms-iso-online
npm install
npm start
```

## 2. 브라우저

**http://localhost:3010**

### Publishable key (첫 화면)

Supabase **pms-iso** → **Settings → API Keys** → Publishable key 붙여넣기 → 저장

### 로그인

Authentication에서 만든 이메일·비밀번호
